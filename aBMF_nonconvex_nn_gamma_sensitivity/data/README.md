# Bundled data

`digits_3_8_prepared.mat` contains:

- PCA-standardized 12-dimensional Digits 3-versus-8 train and test inputs;
- binary labels in \(\{+1,-1\}\);
- a fixed 12-16-1 ReLU classifier;
- three selected correctly classified test indices;
- basic dataset and network metadata.

The fixed network has approximately 99.07% test accuracy on the bundled split.
